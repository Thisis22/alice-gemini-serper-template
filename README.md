# Яндекс Алиса + Groq + Serper на Vercel

Вебхук для навыка Яндекс Алисы. Groq генерирует ответы через совместимый с OpenAI Chat Completions API, а Serper по необходимости ищет актуальную информацию в интернете. История диалога передаётся через состояние сессии Алисы. Секретные ключи хранятся только в переменных окружения Vercel.

## Что умеет проект

- Отвечать на вопросы по-русски коротко, в формате, удобном для голосового помощника.
- Сохранять ограниченную историю разговора между репликами.
- Вызывать Serper для запросов о текущих событиях, новостях, погоде, ценах и других актуальных данных.
- Работать без Serper, если настроен только Groq.
- Ограничивать время внешних запросов и длину ответа под требования навыка Алисы.
- Возвращать корректный JSON для Яндекс Диалогов.

## 1. Создайте API-ключ Groq

1. Откройте официальный сайт GroqCloud: https://console.groq.com/keys
2. Войдите или создайте аккаунт.
3. Создайте API-ключ и скопируйте его. Не отправляйте ключ в чат и не добавляйте его в код или GitHub.

По умолчанию используется модель `openai/gpt-oss-20b`. Модель и бесплатные лимиты могут меняться, поэтому проверяйте доступные модели и лимиты в официальной документации:
- Модели: https://console.groq.com/docs/models
- Лимиты: https://console.groq.com/docs/rate-limits
- API: https://console.groq.com/docs/api-reference

## 2. Настройте переменные в Vercel

Откройте проект в Vercel → **Settings → Environment Variables** и добавьте:

| Переменная | Обязательна | Значение |
| --- | --- | --- |
| `GROQ_API_KEY` | Да | Ваш секретный API-ключ Groq |
| `GROQ_MODEL` | Нет | По умолчанию `openai/gpt-oss-20b`; задайте другую модель, если она доступна вашему аккаунту |
| `SERPER_API_KEY` | Нет | Ключ Serper для поиска в интернете |

Для каждой переменной выберите окружение **Production**. Если используете Preview или Development, добавьте переменные и в эти окружения отдельно. После изменения переменных запустите новый деплой, чтобы настройки применились.

Serper можно получить на https://serper.dev. Без `SERPER_API_KEY` генерация ответов продолжит работать, но поиск актуальной информации будет отключён.

## 3. Деплой и подключение Алисы

1. Убедитесь, что ветка с изменениями Groq объединена с `main`, если проект развёртывается автоматически из production-ветки.
2. В Vercel откройте **Deployments** и дождитесь успешного Production-деплоя со статусом **Ready**.
3. Откройте адрес проекта с окончанием `/api`, например `https://YOUR-PROJECT.vercel.app/api`. Проверка должна вернуть JSON с `"ok": true`.
4. В консоли Яндекс Диалогов откройте навык и укажите полный адрес `https://YOUR-PROJECT.vercel.app/api` в поле **Webhook URL**: https://dialogs.yandex.ru/developer/
5. Сохраните настройки и проверьте навык через тестирование в консоли.

GET-проверка подтверждает, что вебхук запущен, но не проверяет валидность ключа Groq. Для этого отправьте вопрос в тестовом интерфейсе Алисы.

## 4. Локальная проверка

Требуется Node.js 22 или новее.

```bash
npm test
```

## Переменные окружения

- `GROQ_API_KEY` — обязательный секретный ключ для генерации.
- `GROQ_MODEL` — необязательный идентификатор модели Groq.
- `SERPER_API_KEY` — необязательный ключ для поиска.

Не публикуйте ключи в коде, GitHub, README, Яндекс Диалогах или сообщениях. Храните их только в защищённых переменных окружения Vercel.

## Если Алиса не отвечает

1. Проверьте, что `GROQ_API_KEY` существует в окружении **Production** и не содержит лишних пробелов.
2. Проверьте, что ключ активен и доступен выбранной модели в GroqCloud.
3. Посмотрите лимиты модели и организационные лимиты в GroqCloud. При превышении лимита API может вернуть HTTP 429.
4. Убедитесь, что Webhook URL заканчивается на `/api` и ведёт на актуальный production-домен Vercel.
5. Проверьте статус последнего деплоя. Вебхук должен быть доступен Яндексу без интерактивного входа в Vercel.
6. Если ответы на актуальные вопросы не используют поиск, проверьте `SERPER_API_KEY`. Поиск запускается только для распознанных запросов, которым могут требоваться свежие сведения.

## Важное про бесплатный тариф

Groq предлагает бесплатный уровень с ограничениями на число запросов и токены. Точные ограничения зависят от модели и аккаунта; это не безлимитный API. Проверяйте актуальные значения в официальной таблице лимитов: https://console.groq.com/docs/rate-limits.
