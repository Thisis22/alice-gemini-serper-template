# Яндекс Алиса + DeepSeek + Serper на Vercel

Вебхук для навыка Яндекс Алисы. DeepSeek формирует ответы, а Serper по необходимости ищет актуальную информацию в интернете. Секретные ключи хранятся только в переменных окружения Vercel.

## Настройка

1. Откройте проект в Vercel и перейдите в **Settings → Environment Variables**.
2. Добавьте **DEEPSEEK_API_KEY** со своим API-ключом DeepSeek. Создать ключ можно в [платформе DeepSeek](https://platform.deepseek.com/).
3. Добавьте **SERPER_API_KEY** со своим ключом Serper с сайта [serper.dev](https://serper.dev). Эта переменная необязательна: без неё ответы DeepSeek работают, но веб-поиск отключён.
4. При желании добавьте **DEEPSEEK_MODEL**. По умолчанию используется **deepseek-chat**. Укажите только модель, доступную вашему API-аккаунту.
5. Выберите окружение **Production** для переменных и сохраните их.
6. Откройте **Deployments** и запустите новый Production Deployment (или Redeploy последнего коммита). Дождитесь статуса **Ready**.
7. В **Settings → Domains** скопируйте домен проекта и добавьте **/api**, например `https://YOUR-PROJECT.vercel.app/api`.
8. В консоли [Яндекс Диалогов](https://dialogs.yandex.ru/developer/) укажите этот полный адрес в поле **Webhook URL** навыка и сохраните настройки.
9. Включите использование хранилища данных навыка, если эта опция доступна, чтобы сохранялся контекст диалога.

## Проверка

Откройте адрес `https://YOUR-PROJECT.vercel.app/api` в браузере. Должен появиться JSON со значением `"ok": true`. Это проверяет доступность вебхука, но не проверяет DeepSeek API-ключ. Полноценный тест проведите в разделе **Тестирование** Яндекс Диалогов или голосом, если навык уже доступен для тестирования.

## Переменные окружения

- **DEEPSEEK_API_KEY** — обязательный секретный ключ для генерации ответов.
- **DEEPSEEK_MODEL** — необязательное имя модели; по умолчанию `deepseek-chat`.
- **SERPER_API_KEY** — необязательный ключ для веб-поиска по актуальным запросам.

Не вставляйте ключи в исходный код, GitHub, README, Яндекс Диалоги или сообщения. Добавляйте их только в Vercel → Settings → Environment Variables. После изменения переменных выполните новый деплой, чтобы они применились.

## Если навык не отвечает

1. Убедитесь, что Production-переменная `DEEPSEEK_API_KEY` задана без пробелов и опечаток.
2. Проверьте, что у API-аккаунта DeepSeek есть доступ и средства/лимит для запросов.
3. Проверьте, что Webhook URL указывает на ваш собственный домен и заканчивается на `/api`.
4. Проверьте, что последнее развёртывание имеет статус **Ready** и запросы не блокируются защитой Vercel. Внешний вебхук Яндекса должен быть доступен без интерактивной авторизации; если включена SSO-защита, настройте публичный production-домен и убедитесь, что запросы к нему не требуют входа.
5. Учитывайте, что Яндекс Алиса ждёт быстрый ответ. Веб-поиск ограничен по времени, чтобы не задерживать генерацию.

## Разработка

Node.js 22 или новее. Запуск тестов: `npm test`.
